# Scrub- tool to do automatic feature engineering

A prominent tool called "featurewiz" provides automatic feature engineering capabilities. It can create hundreds of new features such as interactions, group-by features, and target-encoded categorical variables with minimal effort. featurewiz also uses advanced feature selection algorithms like MRMR (Minimum Redundancy Maximum Relevance) combined with SULOV and recursive XGBoost to select the most important and non-redundant features for your model. It even incorporates deep learning methods like Variational Auto Encoders to capture complex feature interactions. The tool is designed to be user-friendly and highly efficient, suitable for competitive data science contexts such as Kaggle.

Other notable tools for automated feature engineering include:

- Featuretools: A widely-used library that uses deep feature synthesis to construct and select features automatically from relational databases.
- Autofeat: Automates creation of non-linear features and feature selection to improve model accuracy.
- PyCaret: Offers automated feature engineering as part of its easy-to-use machine learning pipeline, handling encoding, scaling, and missing values automatically.

Each tool varies in functionality and ease of use but collectively aim to reduce the manual effort of feature engineering by creating, transforming, and selecting the best features for machine learning models through automation and advanced algorithms.[^1][^2][^3][^4][^7]
